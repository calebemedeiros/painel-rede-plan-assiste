# Implantação pela DTI

1. Baixe o artefato aprovado do painel.
2. Publique todo o conteúdo de `dist/`.
3. Ajuste `assets/config.js` somente se o catálogo usar outra origem.
4. Mantenha HTTPS e os cabeçalhos de segurança recomendados.
5. Confirme o carregamento do manifesto `4.1.0`.
6. Antes de configurar fontes, confirme a mensagem “Aguardando configuração das fontes”.
7. Depois da autorização, valide uma amostra de cada API direta e indireta configurada.

O frontend e o catálogo são independentes. O pacote inicial não incorpora qualquer base real.
